## Week 3: Variables, Data Types, Expressions and Input/Output
### Objectives
- Declare and use variables.
- Perform arithmetic calculations.
- Receive keyboard input using `Scanner`.
- Display program results.
- Compile and test Java programs.

### Programs
1. `week03/SimpleCalculator.java` — performs addition, subtraction, multiplication and division on two numbers.
2. `week03/AverageCalculator.java` — calculates the total and average of three scores.
3. `week03/ItemCost.java` — calculates total cost from quantity and unit price.

### How to run
Open a terminal in the `week03` directory and run each program separately.

```bash
javac SimpleCalculator.java
java SimpleCalculator
```

```bash
javac AverageCalculator.java
java AverageCalculator
```

```bash
javac ItemCost.java
java ItemCost
```

### Testing
Test each program with different valid inputs and check that the results are correct.
